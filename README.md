# Frame Finger Correction

Steam Frameのコントローラーで、指を伸ばしても曲がったままに見える、曲げても曲がりきらない、といった症状を指ごとの補正で緩和します。補正はFrame本体で動作し、PCVRでもPC側の補正アプリは不要です。

**Valve非公式の個人開発ツールです。** 導入前に[注意事項・免責](#注意事項免責)をお読みください。

## できること

- 左右の人差し指・中指・薬指・小指を、指ごとに「0の印」「1の印」の2つで調整
- アプリを開いている間は全部の指を補正。閉じると補正も止まります
- 値は動かすとすぐ反映され、自動で保存
- ゴーグル内でSteamVR自動起動と表示言語を設定
- SteamVR更新後も、内部の構造・入力検証に合格するビルドでは固定プロファイル追加なしで補正

## 対応環境

Steam FrameのLinux ARM64版が対象です。v0.3.1はプレビュー版です。1台のFrameで、2026年11月8日の更新後のSteamVRベータに対する補正効果を確認しました。11月9日には今回の修正版で、保存済みONから準備操作なしの自動検証・左右8指の補正ONまで進むことをログで確認しました。すべての個体や将来のSteamVRビルドでの動作を保証するものではありません。

| 判定 | 動作 |
| --- | --- |
| 既知ビルド | 従来の固定ハッシュ・配置検証を通したうえで、アプリを開いている間、補正します。 |
| 未知ビルドで構造検証合格 | アプリを開くと、通常入力から経路を自動検証します。確認できた指から補正を開始し、全指の入力は待ちません。 |
| 検証失敗 | 補正を有効にせず、画面に理由を表示します。強制有効化はできません。 |

Controllerの接続・入力準備は時間切れなく待ちます。起動時に指を開いたり、曲げ伸ばししたりする準備は不要です。未知ビルドでは各指の最初の通常入力を変更せずに通し、呼び出し先・値・戻り値を確認してから補正します。入力値の変化や全指の同時確認は要求しません。通常入力が届かない間は、その指だけ補正せずに待ちます。実際の動作は画面下の状態表示（「補正中」など）で確認してください。

## インストール・更新

1. [v0.3.1のリリースページ](https://github.com/wassan0330/frame-finger-correction/releases/tag/app-v0.3.1)を開きます。
2. **既存版からの更新時は先にアプリを閉じ、設定を残して旧版をアンインストール**してください。配布アーカイブを展開したフォルダで `python3 stage-frame-release.py uninstall` を実行します。`--purge` は付けません。既存ドライバーへ重ねて導入する操作は拒否されます。
3. Frame側SteamVRが動作している状態で、デスクトップモードのKonsoleからリリースページの1行コマンドを実行します。sudoは不要です。
4. Frame側SteamVRを通常再起動します。
5. ゴーグルの **「＋」→「プログラムを起動」→「Frame Finger Correction」** から開きます。

1行コマンドの `--experimental` は、未知ビルド向けの検証機能を導入する指定です。検証を省略したり、補正を強制的に有効にしたりする指定ではありません。

## 補正の使い方

各指に横線（0〜3）が1本あり、印が2つ付いています。

- **0の印（緑）**：ここより伸ばした状態は、完全に伸ばした扱いになります。最初は0です。
- **1の印（オレンジ）**：ここまで曲げれば、完全に握った扱いになります。最初は1です。

印はレーザーでドラッグするか、`0−` / `0+`（0.01ずつ）と `1−` / `1+`（0.05ずつ）で動かします。0の印は0〜0.9、1の印は0.1〜3.0の範囲です。

- 0と1のままなら、入力はそのまま通ります（補正なしと同じ）。
- **指が曲がりきらない**（特に小指）→ 1の印を下げます。0.4なら、4割曲げただけで握りきった扱いになります。
- **伸ばしても少し曲がって見える** → 0の印を少し上げます。
- 1の印を1より右に置くと、逆に曲がりにくくなります。SteamVRへ渡す値は0〜1に収めます。
- 親指は対象外です。Frameのコントローラーには親指の曲がり具合を表す入力がなく、ボタンやスティックへの接触から推定されているためです。

画面下に「補正中」と出ていれば効いています。「閉じる」でアプリを終了すると補正は止まり、次に開いたときに保存した値で再開します。

1の印を2.0より上で効かせるには、v0.4のドライバーをSteamVRに読み込む必要があります（導入後にSteamVRを通常再起動）。古いドライバーのままだと画面に案内が出て、2.0までで止まります。

v0.3以前の設定は自動で引き継ぎます。手動の指はデッドゾーンが0の印になり、補正対象外・学習モードだった指は0の印が0になります。

## 困ったとき

| 症状 | 確認すること |
| --- | --- |
| ダッシュボードに見当たらない | 「＋」→「プログラムを起動」から開きます。 |
| 接続・入力準備待ち | 両Controllerを接続してください。接続待ちの時間制限はありません。 |
| 経路確認中 | 通常どおり使用してください。準備動作は不要です。確認できた指から補正します。 |
| 未対応・復元未確認と表示 | 理由を記録してください。検証の再試行はFrame側SteamVRの通常再起動後に行います。無限の再接続試行はしません。 |
| 指を曲げにくい | その指の1の印を下げます。0の印が高すぎないかも確認します。 |
| 入力がおかしい・復元未確認 | アプリを閉じます。改善しない場合や再起動の案内が出た場合は、Frame側SteamVRを通常再起動してください。 |

v0.4のドライバーでは、アプリを閉じて開き直しても再起動なしで補正を再開します（毎回、構造・入力の検証をやり直します）。入力値の異常などで止まった場合は、Frame側SteamVRの再起動が必要です。詳細は[互換性と検証](docs/compatibility.md)をご覧ください。

## アンインストール

アプリを閉じ、Frame側SteamVRが動作している状態で、配布アーカイブを展開したフォルダから実行します。

| 操作 | コマンド |
| --- | --- |
| 補正値・言語を残して削除 | `python3 stage-frame-release.py uninstall` |
| 設定・ログも含めて完全削除 | `python3 stage-frame-release.py uninstall --purge` |

## ソースからビルド

v0.3.1のタグ、またはAssetsの `frame-finger-correction-v0.3.1-source.tar.gz` を使います。古いv0.1.0の自動生成Source codeはREADMEのみだったため、v0.1.0の再ビルドには同リリースに添付したソースを使用してください。

Frame上のC++17コンパイラ、Python 3.11以上、Cairoの開発ファイルとpkg-config、Valve OpenVRヘッダーとARM64ランタイムが必要です。既定ではヘッダーを `/opt/steamvr/tools/hellovr_vulkan_linux/src/openvr/headers`、ランタイムを `/opt/steamvr/bin/linuxarm64` から参照します。必要に応じて `STEAMVR_ROOT` / `OPENVR_HEADERS` を指定します。

```sh
FRAME_FINGER_RELEASE=1 FRAME_FINGER_RUNTIME=november-beta \
FRAME_COMPAT_STRUCTURAL_AUDIT=1 FRAME_COMPAT_OBSERVATION_UI=1 \
sh scripts/build-frame-finger.sh build/frame-finger
python3 scripts/package-frame-runtime-candidate.py build/frame-finger frame-finger-correction-v0.3.1-arm64.tar.gz
```

テストは `python3 scripts/run-tests.py` で実行します。[テスト記録](docs/testing.md)も参照してください。自作部分は[MITライセンス](LICENSE)、同梱のValve OpenVRヘッダーは[個別のライセンス](third_party/openvr-driver/LICENSE)に従います。
